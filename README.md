A simple and interactive **RGB Color Generator App** built with **HTML, CSS, and JavaScript**.  
On each button click, the background changes to a randomly generated RGB color, and the exact RGB value is displayed instantly in the input field.

## 🚀 How It Works

1. User clicks the **Change Color** button  
2. JavaScript generates random RGB values (0–255)  
3. Background color updates instantly  
4. Generated RGB code is displayed in the input field
